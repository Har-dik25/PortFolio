# Hardik — AI/ML Engineer Portfolio

A premium, dark-mode-first portfolio website built with vanilla HTML, CSS, and JavaScript. Features rich animations, 3D effects, an AI-themed design, and interactive elements.

## 🔗 Live Demo

> **[har-dik25.github.io/PortFolio](https://har-dik25.github.io/PortFolio)** _(after GitHub Pages is enabled)_

---

## ✨ Features

| Feature | Description |
|---|---|
| **AI-Themed Preloader** | Animated monogram with progress bar |
| **Neural Network Canvas** | Interactive particle background that reacts to mouse |
| **3D Icosahedron** | Rotating wireframe geometry in the hero section |
| **Live Code Editor** | Auto-typing code snippets showcasing real projects |
| **Dynamic Text Rotation** | Typewriter effect cycling through AI/ML phrases |
| **Terminal Emulator** | Simulated terminal with typing commands |
| **3D Tilt Cards** | Perspective-based hover effects on project cards |
| **Skills Constellation** | 3D interactive skills visualization (Three.js) |
| **Project Detail Modal** | Click-to-expand project cards with case studies |
| **Testimonials Carousel** | Auto-rotating testimonials with dot navigation |
| **Dark/Light Theme** | Full theme toggle with smooth transitions |
| **Custom Cursor** | Animated dot + ring cursor with hover states |
| **Sound Effects** | Subtle UI sounds (hover, click, whoosh) |
| **Magnetic Buttons** | Buttons that follow your cursor |
| **Scroll Progress** | Top-bar scroll indicator |
| **Contact Form** | Working form via Web3Forms |
| **Live GitHub Stats** | Real-time repo/follower counts from GitHub API |
| **Availability Banner** | Dismissable "Open to work" banner with cooldown |
| **Code Playground** | In-browser Python (Pyodide) & JS execution |
| **Role-Based Resume** | Highlight sections by role (AI, Data, Backend) |
| **PWA Support** | Manifest + Service Worker for offline capability |
| **SEO Optimized** | OG tags, JSON-LD schema, sitemap, robots.txt |
| **Accessibility** | Skip links, ARIA labels, reduced-motion support |
| **Responsive** | Mobile-first with hamburger nav |

## 🛠 Tech Stack

- **HTML5** — Semantic structure
- **CSS3** — Custom properties, glassmorphism, gradients, animations
- **Vanilla JavaScript** — No framework dependency
- **Google Fonts** — Space Grotesk + JetBrains Mono
- **Font Awesome 6** — Icon library
- **Three.js** (CDN) — 3D skills constellation
- **Pyodide** (CDN) — In-browser Python execution
- **Web3Forms** — Contact form backend

## 🚀 Getting Started

### Local Development

```bash
# Clone the repo
git clone https://github.com/Har-dik25/PortFolio.git
cd PortFolio

# Serve locally (any static server works)
npx serve .
# or
python -m http.server 8000
```

Open `http://localhost:3000` (or `8000`) in your browser.

### Deploy to GitHub Pages

1. Go to repo **Settings → Pages**
2. Set source to **GitHub Actions** or **Deploy from a branch** (main, root `/`)
3. The site will be live at `https://har-dik25.github.io/PortFolio/`
